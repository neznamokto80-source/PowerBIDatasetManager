# План улучшений UI для Power BI Report Server

## Цель
Реализовать три улучшения пользовательского интерфейса для работы с Power BI Report Server:

1. Заменить диалог выбора авторизации на выпадающий список
2. Добавить опцию "Все папки" в комбобокс расположения отчетов
3. Реализовать фильтрацию отчетов по выбранной папке

## Текущее состояние

### 1. Авторизация
Метод `connect_to_powerbi_report_server` в `src/operations/pbirs_operations.py` использует `QMessageBox.question` для выбора между использованием учетных данных и Windows-аутентификацией.

**Текущий диалог:**
- Запрос URL сервера через `QInputDialog.getText`
- Вопрос "Использовать учетные данные для аутентификации?" с кнопками Да/Нет
- Если Да - запрос имени пользователя и пароля

**Требуется:** Заменить вопрос на выпадающий список с вариантами:
- "Авторизация Windows" (использовать текущий контекст Windows)
- "Ввести данные" (запросить имя пользователя и пароль)

### 2. Комбобокс расположения отчетов
Метод `update_folders_combo` в `src/ui/main_window.py` заполняет комбобокс `workspace_combo` списком папок, извлеченных из отчетов.

**Текущее состояние:** Комбобокс содержит только папки (например, `/`, `/folder1`, `/folder1/subfolder`)

**Требуется:** Добавить первую опцию "Все папки", чтобы пользователь мог видеть все отчеты независимо от папки.

### 3. Фильтрация отчетов
Метод `update_pbirs_reports_table` в `src/ui/main_window.py` заполняет таблицу всеми отчетами без фильтрации.

**Требуется:** Добавить фильтрацию отчетов по выбранной папке в комбобоксе:
- Если выбрано "Все папки" - показывать все отчеты
- Если выбрана конкретная папка - показывать только отчеты из этой папки (и ее подпапок)

## Детальный план реализации

### 1. Выпадающий список авторизации

**Файлы для изменения:**
- `src/operations/pbirs_operations.py` - метод `connect_to_powerbi_report_server`

**Шаги:**
1. Создать кастомный диалог или использовать `QInputDialog` с комбобоксом
2. Варианты: "Авторизация Windows", "Ввести данные"
3. Если выбран "Ввести данные" - запрашивать имя пользователя и пароль
4. Сохранить логику: если имя пользователя не указано - использовать Windows-аутентификацию

**Альтернативный подход:** Использовать `QDialog` с формой, содержащей:
- Поле для URL сервера
- Комбобокс выбора типа авторизации
- Поля для имени пользователя и пароля (скрытые/отображаемые в зависимости от выбора)

### 2. Добавление опции "Все папки"

**Файлы для изменения:**
- `src/ui/main_window.py` - метод `update_folders_combo`
- `src/operations/pbirs_operations.py` - метод `_extract_folders_from_reports` (опционально)

**Шаги:**
1. В методе `update_folders_combo` добавить строку "Все папки" в начало списка
2. Убедиться, что при выборе этой опции фильтрация работает корректно
3. Обновить логику в других местах, где используется `workspace_combo.currentText()`

### 3. Фильтрация отчетов по папке

**Файлы для изменения:**
- `src/ui/main_window.py` - метод `update_pbirs_reports_table`
- `src/operations/pbirs_operations.py` - метод `load_pbirs_reports` (или создать новый метод фильтрации)

**Шаги:**
1. Добавить параметр `selected_folder` в `update_pbirs_reports_table`
2. Фильтровать отчеты по полю `Path`:
   - Если `selected_folder` == "Все папки" или пустая строка - показывать все
   - Иначе показывать отчеты, чей `Path` начинается с `selected_folder`
3. Связать выбор в комбобоксе с обновлением таблицы:
   - Добавить обработчик `currentIndexChanged` для `workspace_combo` в режиме server
   - При изменении вызовать фильтрацию отчетов

2. **Добавление опции "Все папки"**

   - Проверить отображение в UI

3. **Реализация фильтрации отчетов**
   - Добавить логику фильтрации в `update_pbirs_reports_table`
   - Связать с комбобоксом
   - Протестировать фильтрацию

4. **Интеграционное тестирование**
   - Проверить весь поток от подключения до фильтрации
   - Убедиться в отсутствии регрессий

## Риски и решения

**Риск 1:** Изменение диалога авторизации может сломать существующую логику подключения.
**Решение:** Сохранить обратную совместимость - если имя пользователя не указано, использовать Windows-аутентификацию.

**Риск 2:** Фильтрация по подпапкам может работать некорректно.
**Решение:** Использовать проверку `report['Path'].startswith(selected_folder + '/')` для включения подпапок.

**Риск 3:** Производительность при большом количестве отчетов.
**Решение:** Фильтрация выполняется на клиенте, количество отчетов обычно не превышает несколько сотен.

## Критерии успеха

1. Пользователь может выбрать тип авторизации через выпадающий список
2. В комбобоксе расположения отчетов присутствует опция "Все папки"
3. При выборе конкретной папки в таблице отображаются только отчеты из этой папки (включая подпапки)
4. При выборе "Все папки" отображаются все отчеты
5. Все изменения работают без ошибок в существующем функционале
