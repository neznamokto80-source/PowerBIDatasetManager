# Тестовые данные для скриншотов

В проект добавлена возможность генерации детерминированных тестовых данных для подготовки скриншотов и демонстрации функциональности.

## Использование демо-данных

### 1. Запуск приложения с демо-данными

Измените файл `src/ui/methods/connection.py`, в методе `initialize_backend` после создания `UIDataProvider` установите seed и demo_mode:

```python
# Пример (строки 46-48):
self.main_window.data_provider = UIDataProvider(self.main_window.integration)
# Добавьте:
self.main_window.data_provider._provider = DataProvider(demo_mode=True, seed=42)
```

Но проще использовать существующий механизм: данные уже содержат поле `refresh_schedule` и реалистичные значения.

### 2. Запуск тестового скрипта для проверки данных

Выполните команду:

```bash
python src/core/data_provider.py
```

Это выведет демо-данные для рабочей области DefaultWorkspace (6 датасетов с разными характеристиками).

### 3. Характеристики демо-датасетов

1. **Sales Dashboard** - Активен, автообновление включено с расписанием (09:00, 18:00, пн-пт)
2. **Financial Reports** - Активен, автообновление включено без расписания
3. **Marketing Analytics** - Активен, автообновление выключено
4. **Customer Insights** - Неактивен, автообновление выключено
5. **Inventory Management** - Ошибка, автообновление выключено
6. **HR Analytics** - Активен, автообновление включено с расписанием (08:00, 20:00, пн, ср, пт)

Все датасеты имеют разное время последнего обновления (от 2 часов до 10 дней назад).

## Поля данных

Каждый датасет содержит следующие поля, используемые UI:

- `id` - уникальный идентификатор
- `name` - название датасета
- `status` - статус ("Активен", "Неактивен", "Ошибка")
- `lastRefreshTime` - время последнего обновления в формате "ГГГГ-ММ-ДД ЧЧ:ММ"
- `refresh_schedule` - расписание автообновления:
  - `enabled` (bool) - включено ли автообновление
  - `times` (list) - список времени обновлений (например, ["09:00", "18:00"])
  - `days` (list) - дни недели (опционально)
- `auto_refresh_enabled` - дублирует enabled
- `isRefreshable` - совместимость со старым кодом
- `nextRefreshTime` - вычисляется позже в `_enrich_dataset_refresh_info`

## Настройка детерминированных данных

Для повторяемой генерации используйте seed:

```python
from src.core.data_provider import DataProvider
provider = DataProvider(seed=42, demo_mode=False)  # случайные, но детерминированные данные
```

## Изменения в логике отображения статистики

После рефакторинга статистика на вкладке "Обзор" отображается следующим образом:

- **"С обновлением"** - количество датасетов с `refresh_schedule.enabled == True`
- **"Последнее обновление"** - время получения данных (текущее время при загрузке)

Эти изменения уже применены в `src/ui/methods/data_loading.py`.

## Подготовка скриншотов

1. Запустите приложение: `python main.py`
2. Подключитесь к Power BI (кнопка "Подключить")
3. Выберите рабочую область "DefaultWorkspace"
4. Перейдите на вкладку "Обзор"
5. Столбец "ID датасета" скрыт (изменение внесено ранее)
6. Статистика показывает актуальные данные

Для демонстрации различных статусов используйте фильтры или выберите разные датасеты в дереве.

## Восстановление оригинального поведения

Чтобы отключить демо-данные, удалите параметр `demo_mode=True` или установите `demo_mode=False`.
