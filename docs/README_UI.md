# Power BI Dataset Monitor & Manager - Графический интерфейс

Современный графический интерфейс для мониторинга и управления Power BI датасетами, построенный на PyQt6.

## ✨ Особенности

- **Современный интерфейс**: Интуитивно понятный UI с вкладками, панелями инструментов и статус-баром
- **Мониторинг в реальном времени**: Отслеживание статусов обновлений датасетов
- **Управление обновлениями**: Включение/отключение автоматического обновления, запуск ручных обновлений
- **История обновлений**: Просмотр истории с фильтрацией по статусу и периоду
- **Пакетные операции**: Массовое управление обновлениями для нескольких датасетов
- **Уведомления**: Настройка оповещений о событиях
- **Экспорт отчетов**: Сохранение отчетов в различных форматах

## 📋 Требования

- Python 3.8+
- PyQt6
- Модули Power BI Monitor (из текущего проекта)

## 🔧 Установка

1. Установите PyQt6:
```bash
pip install PyQt6
```

2. Убедитесь, что все модули Power BI Monitor установлены:
```bash
pip install -r requirements.txt  # если есть файл требований
```

3. Проверьте наличие файлов модулей в папке `modules/`:
   - `connection_manager.py`
   - `data_provider.py`
   - `dependencies.py`
   - `powerbi_client.py`
   - `refresh_manager.py`

## 🖥️ Структура интерфейса

### Главное окно состоит из:

1. **Панель инструментов** (верх):
   - Обновить данные
   - Аутентификация
   - Настройки
   - Справка

2. **Левая панель** (навигация):
   - Выбор рабочей области
   - Список датасетов
   - Фильтры

3. **Центральная панель** (вкладки):
   - **Обзор**: Таблица датасетов с основной информацией
   - **Детали**: Подробная информация о выбранном датасете
   - **История**: История обновлений с фильтрами
   - **Логи**: Журнал событий приложения

4. **Правая панель** (действия):
   - Быстрые действия (пакетные операции)
   - Мониторинг в реальном времени
   - Настройки уведомлений

5. **Статус-бар** (низ):
   - Текущий статус
   - Сообщения
   - Прогресс операций

## 📊 Использование

### 1. Аутентификация
При первом запуске приложение автоматически выполнит аутентификацию в Power BI. Убедитесь, что у вас есть:
- Настроенные учетные данные
- Необходимые разрешения API

### 2. Просмотр датасетов
1. Выберите рабочую область из выпадающего списка
2. Нажмите "Обновить датасеты" для загрузки списка
3. Выберите датасет для просмотра деталей

### 3. Управление обновлениями
Для выбранного датасета доступны:
- **Включить автоматическое обновление**: Настройка расписания
- **Отключить автоматическое обновление**
- **Запустить ручное обновление**: Выбор типа обновления

### 4. Мониторинг
- Включите мониторинг в реальном времени для отслеживания активных обновлений
- Настройте уведомления о важных событиях

### 5. Экспорт данных
- Экспорт таблицы датасетов в CSV/Excel
- Сохранение логов в файл
- Генерация отчетов

## 🛠️ Разработка

### Структура файлов

```
powerbi_monitor_ui.py      # Главное окно приложения
ui_widgets.py              # Кастомные виджеты
ui_integration.py          # Интеграция с бизнес-логикой
test_ui.py                 # Тесты UI
run_ui.py                  # Скрипт запуска
```

### Добавление новых функций

1. **Новый виджет**: Создайте класс в `ui_widgets.py`
2. **Интеграция с данными**: Добавьте методы в `ui_integration.py`
3. **Новая вкладка**: Добавьте в `PowerBIMonitorUI.create_center_panel()`

### Стилизация
Интерфейс использует стандартные стили Qt. Для кастомизации:
- Измените QSS стили в коде
- Используйте `setStyleSheet()` для виджетов
- Настройте цвета через `QPalette`

## 🔧 Устранение неполадок

### Проблема: Ошибка импорта PyQt6
**Решение**: Установите PyQt6:
```bash
pip install PyQt6
```

### Проблема: Ошибка аутентификации
**Решение**:
1. Проверьте учетные данные Power BI
2. Убедитесь в наличии необходимых разрешений API
3. Перезапустите приложение

### Проблема: Не загружаются датасеты
**Решение**:
1. Проверьте подключение к интернету
2. Убедитесь, что выбранная рабочая область существует
3. Проверьте права доступа к рабочей области

### Проблема: Интерфейс медленно работает
**Решение**:
1. Уменьшите частоту обновления в настройках
2. Отключите мониторинг в реальном времени при неактивности
3. Используйте фильтры для уменьшения количества отображаемых датасетов
