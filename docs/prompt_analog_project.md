# Промт для создания аналогичного проекта: Мониторинг и управление ресурсами облачной платформы

## Контекст
Создайте проект, аналогичный существующему "Power BI Dataset Monitor & Manager", но адаптированный для другой облачной платформы (например, Azure Data Factory, AWS Glue, Google BigQuery, Snowflake, или любой другой сервис по выбору). Проект должен включать как консольное приложение, так и графический интерфейс на PyQt6, с модульной архитектурой.

## Цель проекта
Разработать инструмент для мониторинга и управления ресурсами выбранной облачной платформы, позволяющий:
- Просматривать список ресурсов (датасеты, пайплайны, задания и т.д.)
- Управлять их жизненным циклом (запуск, остановка, настройка расписаний)
- Отслеживать статусы выполнения в реальном времени
- Визуализировать историю операций
- Предоставлять удобный интерфейс для пакетных операций

## Архитектурные требования

### 1. Модульная структура
Проект должен состоять из следующих модулей:
- **`<platform>_client.py`** – клиент для работы с API выбранной платформы
  - Аутентификация (OAuth2, API ключи, IAM роли)
  - Базовые методы для получения ресурсов
  - Управление ресурсами (создание, обновление, удаление)
- **`connection_manager.py`** – управление подключениями и сессиями
  - Кэширование токенов
  - Обработка ошибок подключения
  - Поддержка нескольких сред (dev, staging, prod)
- **`data_provider.py`** – абстракция для получения и трансформации данных
  - Кэширование ответов API
  - Преобразование данных в удобные структуры
  - Фильтрация и сортировка
- **`<operation>_manager.py`** (например, `pipeline_manager.py`, `job_manager.py`) – менеджер для управления конкретными операциями
  - Запуск/остановка операций
  - Настройка расписаний
  - Мониторинг статусов
- **`dependencies.py`** – управление зависимостями проекта
  - Проверка установленных пакетов
  - Автоматическая установка недостающих
  - Валидация версий

### 2. Консольное приложение
Создайте основной скрипт `{platform}_monitor.py` с возможностями:
- Интерактивное меню с нумерованными опциями
- Команды для просмотра ресурсов, управления ими, получения статусов
- Поддержка аргументов командной строки (через argparse)
- Логирование операций в файл и консоль
- Конфигурация через файл `.env` или YAML

### 3. Графический интерфейс (PyQt6)
Создайте файл `{platform}_monitor_ui.py` с современным UI:
- **Главное окно** с панелью инструментов, статус-баром и системой вкладок
- **Левая панель** – навигация (выбор проекта/рабочей области, фильтры)
- **Центральная область** – вкладки:
  1. Обзор ресурсов (таблица с основной информацией)
  2. Детали выбранного ресурса (полная метаинформация)
  3. История операций (с фильтрами по дате и статусу)
  4. Логи приложения (журнал событий)
- **Правая панель** – быстрые действия (пакетные операции, настройки уведомлений)
- **Диалоговые окна** для настройки расписаний, аутентификации, фильтров
- **Визуальные индикаторы** статусов (цветовые коды, иконки)
- **Экспорт отчетов** в CSV, JSON, PDF

### 4. Функциональные требования
- **Аутентификация**: Поддержка нескольких методов (интерактивная, через сервисный аккаунт, CLI)
- **Мониторинг в реальном времени**: Автообновление данных каждые N секунд (настраиваемое)
- **Управление расписаниями**: Включение/отключение автоматического запуска, настройка cron-выражений
- **Пакетные операции**: Массовый запуск/остановка ресурсов, применение тегов
- **Уведомления**: Настройка оповещений (email, Slack, Telegram) при определенных событиях
- **Экспорт данных**: Сохранение таблиц и отчетов в различные форматы
- **Поиск и фильтрация**: По имени, тегам, статусу, дате создания

### 5. Технические требования
- **Язык**: Python 3.8+
- **GUI фреймворк**: PyQt6
- **API клиент**: requests, platform-specific SDK (boto3, google-cloud-library, etc.)
- **Конфигурация**: .env файлы, YAML конфиги
- **Логирование**: модуль logging с ротацией логов
- **Тестирование**: unit-тесты для модулей (pytest)
- **Документация**: README с инструкциями по установке и использованию

### 7. Ключевые особенности для промта
- **Модульность**: Каждый компонент независим, легко заменяем
- **Расширяемость**: Возможность добавления новых типов ресурсов и операций
- **Удобство использования**: Интуитивный интерфейс, подробные подсказки
- **Надежность**: Обработка ошибок, повторные попытки, кэширование
- **Кросс‑платформенность**: Работа на Windows, Linux, macOS

## Примеры использования промта

### Для Azure Data Factory:
"Создайте проект мониторинга и управления пайплайнами Azure Data Factory с графическим интерфейсом на PyQt6. Включите модуль для аутентификации через Azure CLI, получение списка фабрик данных, пайплайнов и триггеров, управление запусками пайплайнов, настройку расписаний, просмотр истории выполнений."

### Для AWS Glue:
"Разработайте инструмент для мониторинга заданий AWS Glue с возможностью просмотра списка jobs, их статусов (RUNNING, SUCCEEDED, FAILED), запуска и остановки заданий, настройки crawlers, просмотра логов выполнения через CloudWatch. Реализуйте консольное приложение и GUI на PyQt6."

### Для Snowflake:
"Создайте мониторинг warehouses, databases, schemas и задач Snowflake. Инструмент должен позволять просматривать текущие сессии, запросы, управлять размерами warehouses, отслеживать кредиты. Интерфейс должен включать дашборд с метриками использования."

## Дополнительные указания
- Используйте современные практики Python (type hints, async/await при необходимости)
- Следуйте принципам Clean Code и SOLID
- Обеспечьте подробное логирование для отладки
- Добавьте возможность работы в офлайн-режиме с кэшированными данными
- Реализуйте тему оформления (светлая/тёмная) в GUI
- Поддерживайте локализацию (русский/английский интерфейс)

## Критерии успеха
- Проект может быть запущен одной командой (`python run_ui.py`)
- Все модули проходят базовые unit-тесты
- Интерфейс интуитивно понятен и не содержит критических багов
- Документация содержит пошаговое руководство по настройке и использованию
- Код размещён на GitHub с лицензией MIT
